# 要填的配置

这些值只放在本机的 `.env`。复制 `.env.example` 为 `.env` 再填。不要提交 `.env`，不要把其中任何一项发到 Telegram，也不要贴进聊天记录。

模型现在走 OpenAI 兼容接口。以后换成 DeepSeek 时，只改 `.env` 里的三项，不用改代码。

## Telegram 机器人（服务器收命令）

| 变量 | 填什么 | 从哪来 |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | 机器人 token | 在 Telegram 找 @BotFather，发送 `/newbot`，按提示取 token |
| `TELEGRAM_BOT_USERNAME` | 机器人用户名，不带 `@` 也行 | BotFather 创建完成后的用户名 |
| `TELEGRAM_CHAT_ID` | 私聊的聊天 id | 先留空。运行 `solidus server`，用你的账号给机器人发一句「开始」。服务器控制台会打印这个 id，再写回 `.env` 并重启 |

服务器只从这一个聊天读命令。它不区分这句话是你亲手发的，还是测试客户端发的。

## Telegram 用户会话（客户端发命令）

机器人收不到另一个机器人的消息，所以客户端必须用你的用户账号。

| 变量 | 填什么 | 从哪来 |
| --- | --- | --- |
| `TELEGRAM_API_ID` | 数字 id | 打开 https://my.telegram.org ，登录后进入 API development tools |
| `TELEGRAM_API_HASH` | 一串 hash | 同上 |

然后在项目目录运行：

```powershell
uv run solidus client login
```

按提示输入手机号和验证码。会话写在 `ledger/solidus.session`，这个文件不要提交，也不要发给别人。

请用和机器人的私聊。你在手机上回复 `1`、`2` 或 `3`；客户端用同一个账号发送机械步骤。

## 练习页密码

| 变量 | 填什么 |
| --- | --- |
| `PRACTICE_PASSWORD` | 你自己设的密码，至少 8 位 |

固定账号是 `tester@example.com`。密码不进 Telegram，不进导出的账本。

## 模型

先用 OpenAI：

| 变量 | 示例 |
| --- | --- |
| `OPENAI_API_KEY` | 你的 OpenAI key |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` |
| `OPENAI_MODEL` | `gpt-4o-mini` |

换成 DeepSeek 时改成：

| 变量 | 示例 |
| --- | --- |
| `OPENAI_API_KEY` | 你的 DeepSeek key |
| `OPENAI_BASE_URL` | `https://api.deepseek.com` |
| `OPENAI_MODEL` | `deepseek-chat` |

如果 DeepSeek 返回地址错误，把 `OPENAI_BASE_URL` 改成 `https://api.deepseek.com/v1`。

没有 key 也能把练习页和 Telegram 卡片走通。只有在你选择「起草」时才会调用模型。

## 可以先不改的项

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `PRACTICE_BASE_URL` | `http://127.0.0.1:8765` | 练习页地址 |
| `PRACTICE_DRIVER` | `http` | `http` 提交表单；`playwright` 用浏览器点页面 |
| `CHROME_CDP_URL` | `http://127.0.0.1:9222` | 已打开的调试 Chrome |

Gemini 那一段不会新开浏览器。需要时由你自己打开一次 Chrome：

```powershell
& "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="$env:USERPROFILE\solidus-chrome"
```

`--user-data-dir` 用单独的目录，避免碰到日常配置。这个 profile 里要先登录 Gemini。技能不负责登录 Google。
